

TARGET-LANGUAGE: Martuthunira (mrt), Western Pama-Nyungan, Australia

CORE

1. Concept: 100A-1 (No numeral classification)
   - Target-language realization: Confirmed by WALS 55A-1 (numeral classifiers absent). Numerals directly modify nouns without an intervening classifier.
   - Intended solver inference: If numerals appear in data, the solver recognizes the numeral-noun sequence as a direct modification with no classifier element. This is a negative inference (absence of a pattern).
   - Priority: OPTIONAL

2. Concept: 83A-2 (Dependent marking in noun-numeral phrases)
   - DROPPED. In Estonian, the noun (dependent) takes partitive case in numeral phrases. In Martuthunira, the noun carries its regular case suffix in numeral phrases (head marking, not dependent marking). The specific Estonian phenomenon (numeral-triggered case change) has no natural parallel in Martuthunira. Forcing this concept would create an artificial or misleading puzzle element.

   - Interaction with CORE: Provides the primary means of encoding grammatical relations (see #2 below).

   - Priority: REQUIRED

2. Phenomenon: No verbal person/number marking

   - Difficulty contribution: HIGH — removes a major cue that solvers from agreement-rich languages would expect.
   - Priority: REQUIRED

INTERACTIONS

1. Case system + No verbal person marking + No adpositions (REQUIRED trio)
   - Interaction: These three features together create the central puzzle insight: in Martuthunira, case suffixes on nouns do all the work that (a) verbal agreement, (b) prepositions, and (c) word order do in other languages. The solver must deduce the full case system from context, with no verbal agreement to help identify roles and no prepositions to signal spatial relations.
   - Additional inference enabled: The solver can predict that the case system will be large (10+ cases) because it must cover all the functions that prepositions and verbal agreement would otherwise handle.

2. Case system + Inclusive/exclusive pronouns
   - Interaction: Pronouns carry both person/number/inclusivity AND case. The solver must simultaneously identify multiple features from a single form. The inclusive/exclusive distinction adds a dimension that is not present in most European languages.
   - Additional inference enabled: The solver can use the case marking on pronouns to confirm their grammatical role, and the inclusive/exclusive distinction provides additional contextual information about the discourse participants.

3. Adjoined relative clauses + Adjectives and relative clauses collapsed + Noun-Adjective order
   - Interaction: All three features converge on the same structural position: a modifier following the noun. The solver cannot formally distinguish an adjective from a relative clause — they are the same construction. This creates a genuine ambiguity that the solver must reason about.
   - Additional inference enabled: The solver must use semantic and contextual cues (e.g., presence of a gap, complexity of the modifier) to determine whether a post-nominal modifier is an adjective or a relative clause. This is a non-trivial reasoning challenge.

4. Evidentiality + Tense (three-way)
   - Interaction: Both are verbal suffixes. The solver must segment the verbal morphology into tense and evidentiality components. The order of these suffixes is a puzzle element.
   - Additional inference enabled: The solver can use the interaction between tense and evidentiality to confirm the segmentation (e.g., certain combinations may be more or less frequent).

5. Two possessive classes + Case system + Dependent marking (possessor marked)
   - Interaction: Possessive suffixes are a type of dependent marking (the possessor is marked on the possessed noun). The two-class system means the solver must identify which nouns belong to which class and what the distinguishing property is.
   - Additional inference enabled: The solver can use the possessive class to make predictions about other morphological behavior of the noun (e.g., whether it takes certain case suffixes differently).

6. SVO + Case marking + No verbal person marking
   - Interaction: In a language with no verbal person marking, word order and case marking are the two primary means of identifying grammatical roles. The SVO order provides a default, but case marking can override or confirm it. The solver must learn to use both cues together.
   - Additional inference enabled: The solver can identify cases where word order and case marking disagree (e.g., topicalization or focus), which reveals additional discourse functions.

7. No adpositions + Rich case system + Demonstrative-Noun order + Numeral-Noun order + Noun-Adjective order
   - Interaction: The modifier order in noun phrases is: Demonstrative-Noun-Adjective (with numerals also preceding the noun). The absence of adpositions means that spatial/relational meaning is in the case suffix on the noun, not in a separate word. The solver can use the modifier order to identify the head noun (the marked element) and the case suffix to identify its grammatical/spatial role.
   - Additional inference enabled: The solver can build a complete model of noun phrase structure: [Dem] [Num] N[Case] [Adj/RelCl].

8. Interrogative-based indefinites + Inclusive/exclusive pronouns
   - Interaction: Both are part of the pronoun system. The solver must identify the full pronoun paradigm, including the relationship between interrogatives and indefinites, and the inclusive/exclusive distinction.
   - Additional inference enabled: The solver can use the morphological relationship between interrogatives and indefinites to confirm the identification of the interrogative forms.

9. Deranked subordinate clauses + Tense + Evidentiality
   - Interaction: Subordinate clauses have reduced verb morphology. The solver must identify what is lost in deranking (e.g., tense, evidentiality, or both) and how this contrasts with main clause verbs.
   - Additional inference enabled: The solver can use the presence or absence of tense/evidentiality marking to identify clause type (main vs. subordinate).

10. Gap relativization + Relativization on obliques not possible + Case system
    - Interaction: Only core arguments (nominative/accusative) can be relativized. The solver can use the case system to predict which arguments are relativizable. The gap in the relative clause is identified by the case on the head noun.
    - Additional inference enabled: The solver can predict that if a noun has an oblique case, it cannot be the head of a relative clause (or rather, the relative clause cannot be formed by gapping that oblique argument).

CONSTRAINTS

1. The puzzle must present sufficient data for the solver to identify at least 5-6 distinct case functions. Each case should appear in at least 2-3 different contexts to allow the solver to triangulate its function.

2. The puzzle must include examples where the verb does NOT change for person/number, making it clear that verbal agreement is absent. At least two different subjects (different persons/numbers) should appear with the same verb form.

3. The puzzle must include examples that demonstrate the absence of adpositions. Spatial/relational meanings should be expressed solely through case suffixes, with no separate preposition/postposition words.

4. If inclusive/exclusive pronouns are included, the data must provide sufficient contextual clues (e.g., discourse context) for the solver to determine which form is inclusive and which is exclusive. At least one example of each should be present.

5. If the adjective/relative clause collapse is included, the data must include at least one clear adjective and one clear relative clause in the same structural position (post-nominal), so the solver can observe the formal identity.

6. If evidentiality is included, the data must provide contextual clues (e.g., narrative framing, reported speech) that allow the solver to identify the evidential function. The evidential suffix should appear in at least 2-3 examples.

7. If two possessive classes are included, the data must include nouns from both classes with the same possessor, so the solver can observe the different possessive suffixes. At least 2-3 nouns from each class should be present.

8. The phonological data (if included) should be consistent with the WALS evidence: small vowel inventory (2-4 vowels), no fricatives, no voicing contrast, no uvulars, no glottalized consonants, /l/ present, initial velar nasal possible.

9. The puzzle should not require the solver to know that Martuthunira is a Pama-Nyungan language or to have any prior knowledge of Australian languages. All relevant properties must be inferable from the data.

10. The source concept 83A-2 (dependent marking in noun-numeral phrases) is DROPPED. The puzzle should NOT include any element that suggests a special numeral-triggered case change on the noun. In Martuthunira, the noun simply carries its regular case in numeral phrases.

11. The puzzle should maintain internal consistency: if a case suffix is identified as marking, e.g., locative, it should consistently mark locative throughout the data. No irregularities should be introduced unless they are part of the puzzle's challenge (e.g., the two possessive classes).

12. Word order should be consistently SVO in the data, with any deviations (e.g., topicalization) being clearly marked or contextually motivated, so as not to confuse the solver about the basic order.
