

TARGET-LANGUAGE

Supyire (Senufo, Niger-Congo, West Africa)

CONSTRUCTION RATIONALE

1. **Establish the basic sentence frame (SOV) and introduce noun morphology in its simplest form.** Present a set of short, affirmative, present-tense sentences with a small set of high-frequency nouns (4–6 nouns spanning at least 3 different noun classes). Each sentence should contain a subject, an object, and a verb in SOV order. The nouns should appear in both singular and plural, and in both definite and indefinite forms. Use simple, concrete vocabulary (body parts, animals, food, natural objects) to minimize lexical interference. The solver should be able to infer from this initial data: (a) the basic word order is SOV; (b) nouns carry suffixal morphology; (c) there is a suffix that marks plurality (obligatory, since it appears in all plural instances); (d) there is a suffix that marks definiteness (since it appears only in some instances and correlates with semantic definiteness in the glosses). At this stage, the solver should NOT yet be able to identify the noun class system, because the definite suffix forms should be varied enough to hint at a pattern but not yet sufficient to group nouns into classes. The key inference enabled here is the identification of the morphological order: the solver must determine whether the order is Noun-Plural-Definite or Noun-Definite-Plural. Ensure that at least one noun appears in all four combinations (singular-indefinite, singular-definite, plural-indefinite, plural-definite) so the order is unambiguous.

2. **Introduce the noun class system through systematic variation in the definite suffix.** Expand the noun inventory to include 8–12 nouns, ensuring that at least 4–5 distinct definite suffix forms are represented. The nouns should be chosen so that the class assignment is recoverable from a combination of semantic and formal cues: for example, one class might include animate beings, another inanimate objects, another natural phenomena, another abstract or body-part nouns. The solver should now be able to group nouns by their definite suffix form and hypothesize a class system. To make this inference robust, include at least one pair of nouns that are semantically similar but belong to different classes (showing that semantics alone is insufficient), and at least one pair that are semantically different but share a class (showing that formal/phonological criteria also play a role). The 3rd person pronouns should be introduced in this stage: include sentences where a 3rd person pronoun replaces a noun, and the pronoun form should correspond to the noun's class. This gives the solver an independent confirmation of the class system. The solver should now be able to: (a) identify the number of noun classes; (b) assign a class to any noun based on its definite suffix; (c) predict the 3rd person pronoun form for a given noun class.

3. **Introduce the negation system through controlled contrasts between affirmative and negative sentences.** Present a set of sentence pairs: each pair consists of an affirmative sentence and its negative counterpart, using the same verb and arguments. The negative sentences should display the double negation pattern: an obligatory postverbal negative element (appearing immediately after the verb) and an optional preverbal negative element (appearing before the verb, between subject and object). To make the optionality discoverable, include some negative sentences with both elements and some with only the postverbal element. The solver should be able to infer: (a) negation is not a single morpheme but involves two elements; (b) the postverbal element is obligatory (it appears in all negative sentences); (c) the preverbal element is optional (it appears in some but not all negative sentences). At this stage, keep the tense/aspect constant (e.g., all present tense) so that the solver can isolate the negation pattern without the confound of tense/aspect variation. The solver should also be able to identify the position of each negative element relative to the SOV frame: the preverbal element appears between S and O (or between S and V, depending on the exact pattern), and the postverbal element appears immediately after V.

4. **Introduce the tense/aspect system through verb form variation across temporal contexts.** Present a set of sentences using one or two high-frequency verbs across different tense/aspect contexts: past (with at least two degrees of remoteness if possible), non-past, and perfective/imperfective aspect. The verb forms should be suppletive in at least some combinations (i.e., the stem changes in ways that are not derivable by simple affixation). The solver should be able to infer: (a) there is a tense/aspect system with multiple categories; (b) some verb forms are suppletive (the stem is not predictable from other forms); (c) the verb carries multiple grammatical categories in a single word (monoexponential TAM). To make the suppletion discoverable, ensure that at least one verb shows a clear pattern where most forms share a stem but one or two forms have a completely different stem. The solver should be able to identify the categories (e.g., past-remote, past-recent, non-past, perfective, imperfective) and the form of each category for the verbs presented.

5. **Introduce asymmetric negation by showing that the negation pattern varies with tense/aspect.** Now present negative sentences in different tense/aspect contexts. The key contrast: in some tense/aspect forms, the full double negation pattern (preverbal + postverbal) is obligatory or strongly preferred, while in others, only the postverbal element appears (or the pattern is otherwise different). This is the A/Fin and A/Cat asymmetry: the negation pattern differs depending on the finiteness or aspectual form of the verb. The solver should be able to infer: (a) the negation pattern is not uniform across all verb forms; (b) the distributional condition for the preverbal element is tied to a specific grammatical property (e.g., finiteness, or a specific aspectual value); (c) the full negation system has at least two patterns with different distributional conditions. This step depends critically on the discoveries from steps 3 and 4: the solver must already know the basic negation pattern (step 3) and the tense/aspect categories (step 4) before they can identify the asymmetry.

6. **Introduce additional head-final evidence to consolidate the typological profile.** Include a small number of sentences that demonstrate postpositions (adpositions following the noun), noun-adjective order (adjective following the noun), and genitive-noun order (possessor preceding the possessed). These should be presented as additional data points rather than as a separate focus. The solver should be able to infer that the head-final pattern is consistent across multiple domains, reinforcing the SOV discovery from step 1. This also provides a predictive tool: if the solver encounters a new modifier or adposition, they can predict its position based on the head-final pattern.

7. **Design the production/generalization tasks.** Create a set of English sentences that the solver must translate into Supyire. These tasks should test the full range of discovered rules and require productive generalization. Design constraints:
   - Include at least one sentence requiring the solver to assign a noun to a class and produce the correct definite suffix for a noun that did not appear in the data (testing productive generalization of the class system).
   - Include at least one sentence requiring the correct morphological order of plural and definite suffixes on a novel noun.
   - Include at least one negative sentence in a tense/aspect context where the asymmetric negation pattern applies differently from the basic pattern (testing the interaction of negation and tense/aspect).
   - Include at least one negative sentence in a context where only the obligatory postverbal element is required (testing that the solver understands the optionality).
   - Include at least one sentence in a tense/aspect form that was not explicitly shown in the data but can be predicted from the pattern (testing generalization of the TAM system).
   - Include at least one sentence with a postpositional phrase or an adjective, testing the head-final pattern.
   - Progress in complexity: start with sentences requiring 2–3 rules simultaneously, then move to sentences requiring 4–5 rules.
   - Ensure that no single production item tests only one rule in isolation; each item should require the integration of multiple discovered patterns.

8. **Apply solvability and non-triviality constraints.** Verify the following:
   - Every rule the solver must discover is supported by at least two independent data points (no rule should be inferable from a single example).
   - The noun class system is discoverable without prior knowledge: the class assignments should be recoverable from the definite suffix forms alone (with the 3rd person pronouns as confirmation). The semantic criteria should be suggestive but not the sole basis (to prevent the solver from guessing classes purely from meaning).
   - The negation asymmetry is discoverable: the data must include enough negative sentences in different tense/aspect contexts for the solver to identify the distributional condition. If the preverbal element appears in, say, 6 out of 10 negative sentences, the solver must be able to identify the property that distinguishes those 6 from the other 4.
   - The suppletive verb forms are identifiable: the solver should be able to recognize that a particular form is suppletive (not derivable by regular affixation) because it is the only form of that verb with a different stem, and the contrast should be clear.
   - No rule requires the solver to know Supyire-specific phonology (tone, nasal vowels) unless those features are directly relevant to a morphological contrast being tested. If tone is included, it must be marked consistently and must be contrastive (different tones must correspond to different grammatical forms or different words).
   - The data should not include passive, antipassive, or applicative constructions (these are absent in Supyire). The solver should not be able to infer their existence.
   - The overall difficulty should be such that a solver who correctly extracts all rules from the data can answer all production items, but a solver who misses even one rule (e.g., the noun class system, or the negation asymmetry) will get specific items wrong. This ensures the puzzle discriminates between partial and complete understanding.

9. **Structure the data presentation for progressive discovery.** The data should be organized in a way that guides the solver through the discovery sequence. A recommended structure:
   - **Part A (Discovery data):** Present the data in a sequence that mirrors the construction steps above. Start with simple affirmative sentences (step 1), then expand to show class variation (step 2), then introduce negation (step 3), then tense/aspect (step 4), then asymmetric negation (step 5), and finally the additional head-final evidence (step 6). Each part should be labeled or separated so the solver can focus on one set of phenomena at a time.
   - **Part B (Identification/analysis questions):** Ask the solver to explicitly state the rules they have discovered (e.g., "What is the word order?", "How many noun classes are there? What is the definite suffix for each class?", "What is the negation pattern? Which element is obligatory?"). These questions serve as checkpoints and help the solver organize their understanding before attempting production.
   - **Part C (Production questions):** The translation tasks from step 7. These test whether the solver can apply the discovered rules productively.

10. **Control for competing hypotheses and ambiguity.** At each stage, ensure that the data rules out the most likely alternative hypotheses:
    - For the definite suffix: ensure that the suffix is not confusable with a plural marker or a case marker. The contrast between definite and indefinite forms of the same noun (same number, same class) should make it clear that the suffix marks definiteness, not number or case.
    - For the noun class system: ensure that the definite suffix variation is not confusable with allomorphy conditioned by phonological environment. If the suffix form could be explained by the final segment of the noun stem, include at least one pair of nouns with the same final segment but different classes (or different final segments but the same class) to rule out a purely phonological explanation.
    - For the negation: ensure that the preverbal element is not confusable with a subject marker or a focus particle. The contrast between sentences with and without the preverbal element (same subject, same verb, same object, only the negation differs) should make its function clear.
    - For the tense/aspect: ensure that the verb form variation is not confusable with person/number agreement (which is absent in Supyire). Since there is no person marking, the verb form variation can only be due to tense/aspect, which simplifies the inference.
    - For the asymmetric negation: ensure that the distributional condition is not confusable with a semantic factor (e.g., the preverbal element does not appear only with certain verbs or certain semantic types). The condition should be purely grammatical (tense/aspect or finiteness).
