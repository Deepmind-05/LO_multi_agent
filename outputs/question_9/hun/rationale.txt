

TARGET-LANGUAGE: Hungarian

CONSTRUCTION RATIONALE

1. **Establish the fundamental data architecture.** The puzzle will present inflected forms organized into three paradigmatic domains: (a) nominal inflection (plural + case), (b) possessive suffixes, and (c) verbal agreement. All three domains are governed by the same underlying vowel harmony system. The solver's task is to discover this system from the nominal data and then transfer it to the other domains. The overall structure mirrors the source rationale's noun→verb correspondence, but the "correspondence" here is not between singular and plural forms of the same root; rather, it is between the harmony rules governing nominal suffixes and those governing verbal agreement suffixes. The root itself never changes; all alternation is in the suffix vowel.

2. **Design the noun data to reveal the two-dimensional harmony system.** This is the central inferential challenge of the puzzle. The solver must discover that suffix vowel selection is governed by TWO independent binary dimensions (front/back and rounded/unrounded), not a single undifferentiated alternation. To make this discoverable, the noun data must include roots from all four harmony classes: back-unrounded (root contains only /a/), back-rounded (root contains only /o/ or /u/), front-unrounded (root contains only /e/), and front-rounded (root contains only /ö/ or /ü/). The critical contrasts are: (a) a back-unrounded root vs. a back-rounded root, which isolates the rounding dimension; (b) a back-unrounded root vs. a front-unrounded root, which isolates the front/back dimension; (c) a front-unrounded root vs. a front-rounded root, which again isolates rounding. The solver should be able to observe that the suffix vowel changes along both dimensions independently. Provide at least 3–4 nouns per harmony class to allow reliable induction. All roots must have unambiguous, internally consistent vowel quality (no mixed front/back or mixed rounded/unrounded vowels within a single root). Provide semantic glosses for all forms, but make clear that semantics plays no role in the solution.

3. **Introduce the plural suffix as the first harmonic evidence.** Present the plural suffix in its four surface forms (-k, -ok, -ek, -ök) distributed across the four harmony classes. The solver's first inference should be: "the suffix vowel matches some property of the root." The second, harder inference is: "there are two independent properties, not one." The -k form (back-unrounded) is particularly important because it lacks a visible vowel, which forces the solver to recognize that the absence of a vowel is itself a harmonic signal (the suffix is "unrounded back" with no vowel). This creates a subtle asymmetry: three of the four classes show an overt vowel in the suffix, while one does not. The solver must still correctly assign this root to the back-unrounded class. This is a useful difficulty point that does not undermine solvability, because the contrast with the -ok form (back-rounded) makes the distinction clear.

4. **Introduce case suffixes as confirmatory evidence.** Present 2–3 case suffixes (e.g., dative, inessive, or locative) in their harmonic variants. The purpose of this step is not to introduce new inferential challenges but to confirm the generality of the harmony system. The solver should observe that the same two-dimensional pattern holds across multiple different suffixes, strengthening confidence in the discovered rules. The case suffixes should use the same four-way vowel alternation as the plural suffix (e.g., -ba/-ra/-be/-re for dative). This step also introduces the concept that the harmony class is a property of the ROOT, not of any particular suffix, since different suffixes on the same root all show the same harmonic pattern.

5. **Introduce possessive suffixes to add the person/number dimension.** Present a full possessive paradigm (1sg, 2sg, 3sg, 1pl, 2pl, 3pl) for at least two roots from different harmony classes. The possessive suffixes have the same two-dimensional harmonic structure as the plural and case suffixes, but they additionally encode person and number. The solver should discover: (a) the harmony rules are the same as those already established from plural and case data (confirmation), and (b) there is an additional person/number dimension that is independent of harmony. The person/number dimension should be presented as a set of consonantal or segmental markers (e.g., -m, -d, -ja, -nk, -tok, -ik) that are invariant with respect to harmony, while the vowel within the suffix (where present) follows harmony. This creates a two-dimensional system: person/number × harmony class. The structural parallel with verbal agreement (which will be introduced in step 7) should be transparent: both possessives and verbal agreement have the same person/number set and the same harmonic behavior.

6. **Introduce agglutinative stacking to provide redundant confirmation within single forms.** Present 2–3 complex forms where multiple suffixes are stacked on a single root (e.g., root + plural + dative, or root + possessive + inessive). All suffixes in the stack should show the same harmonic pattern, consistent with the root's harmony class. The purpose of this step is twofold: (a) it provides redundant confirmation of the harmony rules within a single surface form, making the rules more robustly inferable; and (b) it introduces the concept of morpheme decomposition—the solver must recognize that a complex surface form is composed of multiple morphemes, each independently showing harmony. This step does not introduce new rules but adds surface complexity that the solver must parse. It also creates a useful self-check: if the solver's harmony analysis is correct, all suffixes in a complex form should be consistent with the root's class.

7. **Introduce verbal agreement as the cross-paradigm transfer.** Present 3–5 verb stems with their full agreement paradigms (1sg through 3pl). The verb stems should have different vowel qualities from the noun roots used earlier (to confirm that the harmony rules are general, not idiosyncratic to specific roots). The agreement suffixes should follow the same two-dimensional harmony pattern as the nominal suffixes. The critical inference the solver must make is: "the same harmony rules that govern nominal suffixes also govern verbal agreement suffixes." This is the key "aha" moment of the puzzle, analogous to the verb-noun correspondence in the source rationale. The solver should be able to predict verbal agreement forms using the harmony rules learned from nominal data. To make this transfer explicit, include at least one verb stem whose harmony class matches a noun root's class, so the solver can directly compare the suffix forms and see they follow the same pattern. The person/number dimension in verbal agreement should use the same set as in possessives (1sg, 2sg, 3sg, 1pl, 2pl, 3pl), making the structural parallel between possessives and verbal agreement transparent.

8. **Design the question sequence with progressive difficulty.** The questions should be ordered to match the discovery sequence: (Q1) Harmony class identification: present 5–7 noun roots (uninflected) and ask the solver to assign each to a harmony class. This tests whether the solver has correctly identified the two-dimensional system. Include at least one root from each of the four classes. (Q2) Plural/case prediction: present 6–8 noun roots with the plural or a case form missing. The solver must predict the correct suffix form. Distribute items so that some test only the front/back dimension, some test only the rounding dimension, and some test both simultaneously. Include at least one item where the root's harmony class is the same as a training root but the specific consonants differ (testing generalization beyond specific roots). (Q3) Possessive prediction: present 4–6 items where the solver must predict a possessive form, requiring them to apply both the person/number marking and the harmony rule simultaneously. This tests whether the solver can handle two dimensions at once. (Q4) Verbal agreement prediction: present 3–4 verb stems with one or more agreement forms missing. The solver must apply the harmony rules (learned from nominal data) to predict the verbal forms. This is the cross-paradigm transfer question. Include at least one item where the verb stem's harmony class is the same as a noun root's class, so the solver can verify their answer by comparing with the nominal data. (Q5) Explanation: ask the solver to state the harmony rules explicitly, describe the two dimensions, and explain how the rules apply across all three domains (nominal, possessive, verbal). This ensures the solver has a coherent theoretical account.

9. **Design controlled contrasts to distinguish competing hypotheses.** The most important competing hypothesis to rule out is: "there is only one dimension (e.g., front vs. back), and rounding is irrelevant." To rule this out, the data must include a clear contrast between a back-unrounded root and a back-rounded root (showing different suffix vowels) and between a front-unrounded root and a front-rounded root (showing different suffix vowels). Similarly, to rule out the hypothesis "there is only one dimension (rounded vs. unrounded), and front/back is irrelevant," the data must include a contrast between a back-unrounded root and a front-unrounded root. The solver should be able to see that both dimensions independently affect the suffix form. A second competing hypothesis is: "the suffix vowel is determined by the last vowel of the root" (or some positional rule). To rule this out, include roots where the first and last vowels are the same (so positional rules cannot be distinguished from the correct rule) and roots where they differ but the harmony class is unambiguous (so the solver can see that the overall vowel quality, not a specific position, determines the suffix).

10. **Verify solvability and absence of unintended ambiguity.** Check that: (a) every harmony class is uniquely identifiable from the vowel content of the root (no root in the puzzle data has ambiguous harmony); (b) the verbal agreement data does not introduce any pattern not already visible in the nominal data (the verbs should confirm, not contradict, the nominal harmony rules); (c) the possessive data is consistent with both the nominal harmony rules and the person/number system (no possessive form should be incompatible with the root's harmony class); (d) no question item can be solved by simple analogy to a single training example without applying the abstract rule (i.e., the roots in question items should differ from the training roots in at least one phonological feature); (e) the total number of distinct features the solver must track (front/back, rounded/unrounded, person/number, morpheme type) is sufficient to make the problem challenging but not so high that the patterns become impossible to induce from the given data. The two-dimensional harmony system plus the person/number dimension plus the cross-paradigm transfer should provide sufficient complexity without requiring the solver to track more than three independent dimensions simultaneously.
