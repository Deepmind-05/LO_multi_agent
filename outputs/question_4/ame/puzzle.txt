QUESTIONS

**Q1 (2 marks).** In the possessive constructions in Table 1, which element bears the possessive marking – the possessor or the possessed noun? Identify the two dimensions of variation in the marking.

**Q2 (3 marks).** Based on Table 1, identify the possessive classes in Amele. For each class, list all nouns that occur in the possessed position and belong to it. (Note: nouns that appear only in the possessor position, such as *sɨm* and *tɨr*, cannot be assigned a possessive class from the given data.)

**Q3 (2 marks).** Table 2 provides additional evidence about the nature of the noun classification system. Explain why the classes identified in Q2 are (a) not a grammatical gender system, and (b) not a numeral classifier system.

**Q4 (2 marks).** In Table 3, the word *wɨ* appears in different contexts. Identify the grammatical function of *wɨ* in each sentence (1–6). What is the relationship between these functions?

**Q6 (2 marks).** The possessive suffix paradigm in Table 1 contains three forms that deviate from the regular pattern. Identify each irregular form (give the table number and the surface form) and state the phonological rule that accounts for it.

ANSWERS

**Q1.** The possessor bears the marking (dependent marking). The marking encodes two dimensions: (i) the person and number of the possessor, and (ii) the possessive class of the possessed noun.

**Q2.** There are five possessive classes:

- **Class A:** tɨm (head), sɨw (shadow)
- **Class B:** kɨr (dog), kɨw (canoe)
- **Class C:** tɨl (tree), dɨl (banana)
- **Class D:** gɨl (house), kɨn (knife)
- **Class E:** mɨr (name), sɨl (dream)

**Q3.** (a) The classes are not a grammatical gender system because the modifiers in Table 2 (adjective *tɨ*, demonstrative *kɨ*) follow the noun and remain invariant regardless of the noun's possessive class. In a gender system, modifiers would be expected to agree with the noun's class. (b) The classes are not a numeral classifier system because the numeral *mɨ* follows the noun and remains invariant regardless of the noun's class (cf. *tɨm mɨ*, *kɨr mɨ*, *tɨl mɨ*, *sɨmɨn mɨ*). In a classifier system, the numeral would be expected to take a class-specific form.

- Sentence 4: predicative possessive ("has")

The same lexical item *wɨ* serves three functions: coordinative conjunction, comitative, and predicative possessive marker. The interpretation is determined by context (e.g., whether the construction is predicative or adnominal, whether the second NP is a possessed object or a comitative participant).

SOLUTION

**Inferred rules:**

1. **Dependent marking in possessive NPs.** The possessor (dependent) carries a suffix; the possessed noun (head) is unmarked. Evidence: in all Table 1 examples, the first element (possessor) is modified while the second element (possessed noun) remains in its citation form (e.g., *tɨm* appears unchanged in #1, #11, #16, #21, #24, #27, #31).

2. **Five possessive classes.** The suffix consonant is determined by the class of the possessed noun. Evidence: within each person/number value, different possessed nouns trigger different suffix consonants. For example, in 1SG: *aan* (→ tɨm, sɨw), *aar* (→ kɨr, kɨw), *aat* (→ tɨl, dɨl), *aak* (→ gɨl, kɨn), *aaw* (→ mɨr, sɨl). The grouping is confirmed across multiple person/number values.

3. **Person/number encoding.** The suffix vowel encodes the person and number of the possessor: a (1SG), e (2SG), i (3SG), u (1PL), o (2PL), y (3PL). Evidence: comparing across rows in Table 1 (e.g., *aan* vs. *een* vs. *iŋ* vs. *unun* vs. *oŋ* vs. *yyn* for Class A).

4. **Not a gender system.** Modifiers (adjective, demonstrative) follow the noun and are invariant across classes (Table 2, #1–7). If this were a gender system, we would expect class-based agreement on modifiers.

5. **Not a numeral classifier system.** The numeral *mɨ* follows the noun and is invariant across classes, including human nouns (Table 2, #8–11). If this were a classifier system, we would expect class-specific numeral forms.

6. **Human-only plural.** The suffix *-ɨn* marks plural on human nouns (*sɨm* → *sɨmɨn* in Table 2 #11, #12; Table 3 #4). Non-human nouns show no plural marking even in plural contexts (e.g., *kɨr mɨ* "two dogs" in Table 2 #9 has no plural marker on *kɨr*). This is a separate, simpler classification (human vs. non-human) that is orthogonal to the possessive class system.

7. **Conjunctional possessive.** Predicative possession ("X has Y") is expressed with *wɨ* (the same word as "and" and "with"), with no possessive suffix on the possessor (Table 3 #1, #4, #6). This contrasts with attributive possession, which uses the class-based suffix (Table 1).

8. **Phonological irregularities.** Two phonological rules account for the three irregular forms: (i) nasal assimilation: n → ŋ after i or o; (ii) final glide deletion: w → ∅ after u.

**How rules produce each answer:**

- Q1: Directly from observation of Table 1 structure.
- Q2: From systematic comparison of suffix consonants across all examples; the "surprise" nouns (sɨw → Class A, kɨw → Class B) are assigned by their suffix, not by semantic intuition. Only nouns appearing in the possessed position are classifiable; possessor-only nouns (sɨm, tɨr) cannot be assigned a class from the data.
- Q3: From the invariance of modifiers and numerals in Table 2.
- Q4: From the English glosses in Table 3; the solver recognizes three distinct functions of the same form.
- Q5: (a) 2SG vowel *e* + Class C consonant *t* → *eit* + *tɨl*. (b) 3PL vowel *y* + Class E consonant *w* → *yw* + *mɨr*. (c) 1SG vowel *a* + Class B consonant *r* → *aar* + *kɨw* (canoe is Class B, not D). (d) Predicative possession: *mɨt wɨ gɨl* (no suffix). (e) Coordinative: *sɨm wɨ kɨl*. (f) 1PL vowel *u* + Class A consonant *n* → *unun* + *sɨw* (shadow is Class A, not D). (g) Human plural + predicative possession: *sɨmɨn wɨ kɨr*. (h) Noun + adjective: *gɨl tɨ*. (i) Noun + numeral: *tɨl mɨ*. (j) Comitative + adjective on second NP: *sɨm wɨ kɨr tɨ*.
- Q6: The solver identifies the expected regular forms by applying the vowel + consonant pattern, notices the deviations, and identifies the phonological rules.

DIFFICULTY

**Level 5.** The puzzle requires the solver to simultaneously reconstruct a multi-class possessive system with dependent marking, distinguish it from gender and classifier systems using negative evidence, identify a three-way functional overlap in a single lexical item, recognize an orthogonal human/non-human plural system, and apply all of these rules in production. The "surprise" nouns (shadow, canoe) require the solver to override semantic intuition in favor of morphological evidence. The irregularities require phonological reasoning. The conjunctional possessive creates a structural contrast with attributive possession that the solver must maintain in production. Multiple interacting concepts create layered inference without any single step being trivially difficult.
